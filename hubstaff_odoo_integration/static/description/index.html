Import Operations (Hubstaff to Odoo)

1. Import projects, tasks, and time entries from Hubstaff into Odoo.

2. Sync team members/users from Hubstaff into Odoo.

3. Automatically handle large datasets with pagination to ensure all records are imported.

4. Receive instant updates in Odoo via webhooks whenever new project and task are created in the hubstaff.

5. Keep Odoo data always up-to-date with Hubstaff.

6. Automate the import process using a scheduled cron job to run at defined intervals.

Export Operations (Odoo to Hubstaff)

1. Export projects and tasks from Odoo to Hubstaff.

2. Update existing projects or tasks in odoo from hubstaff.

3. Maintain correct mappings to avoid duplicates or data conflicts.

4. Automate the export process using a scheduled cron job to run at defined intervals.

01 Instance creation process with it's configuration

Setting up the Hubstaff Instance in Odoo (From this button you can create new instance)

In the instance configuration, set the Instance Name, Company, Client ID, Client Secret Key, and Redirect URI. The Redirect URI should be your live URL from which the Hubstaff synchronization will be performed.

You can obtain the Client ID and Client Secret Key from Hubstaff. Enter these credentials in the respective fields and save the configuration to complete the setup.

After clicking the Authenticate button, you will be redirected to Hubstaff. If prompted, sign in to your account and authorize the application from the authorization popup. Once authorization is completed, you will be redirected back to Odoo, where the required fields such as Authorization Code and Access Token will be automatically filled.

Once authentication is completed, the state is set to Confirmed. If you need to update the credentials later, click Reset to Draft, make the required changes, and authenticate again in Odoo.

In the instance Project/Task Configuration, enable the options as per your requirements. Additionally, select a Failure Activity User — if the export process fails, an activity will be automatically created for the selected user.

Is this application compatible with both Odoo Enterprise and Community editions?

Yes, the application is fully compatible with Odoo Enterprise (On-premise and Odoo.SH) and Community editions. However, it cannot be installed on Odoo Online, as third-party apps are not supported.

Is it possible to manage multiple Hubstaff organizations or instances?

Yes, you can configure and manage multiple Hubstaff instances within Odoo.

Can projects and tasks be imported automatically and manually?

Yes, projects and tasks can be imported manually using operation buttons or automatically through scheduled actions (cron jobs).

Does the integration support real-time synchronization?

Yes, real-time synchronization is supported through webhooks. Projects and tasks created in Hubstaff can be automatically created in Odoo.

How are time entries managed in the integration?

Time entries can be imported from Hubstaff into Odoo either manually or automatically using scheduled automation.

Can projects and tasks be exported from Odoo to Hubstaff?

Yes, projects and tasks can be exported individually from the form view or in bulk from the list view. Automated export actions can also be configured.

What happens if synchronization fails?

If any export process fails, logs are created and a failure activity can be automatically assigned to the configured user for review.
