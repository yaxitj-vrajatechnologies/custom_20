AI VENDOR PRICELIST UPDATE

Community Enterprise Odoo.sh

The Vendor Pricelist AI Update module provides a complete solution for keeping your vendor prices up to date using the power of AI. Instead of comparing the vendor's new price file with your Odoo vendor prices line by line and typing every change by hand, your team generates the current pricelist of the vendor, uploads the file the vendor sent back, clicks one button, and lets the AI do the work. The module uses OpenAI to read both files, match the vendor's products with your Odoo products, the latest prices and prepare the update for the Vendor Pricelist (product.supplierinfo).

Vendors send their new prices in many different ways: Excel sheets, PDF tariffs, Word documents or emails, each with its own structure. The module compares the vendor's file with your current Vendor Pricelist, finds the new price, quantity, discount, transport cost, other fees, lead time, start date and end date for every product, and shows the result in two review tables before anything is changed in Odoo. Products the AI is certain about are separated from products that need your decision, so nothing is guessed. When you are satisfied with the result, one click applies it to the Vendor Pricelist. The module handles the price history automatically: it updates a line when the start date is the same, creates a new line when it is a new start date, and closes the previous open line the day before the new start date.

Every run is fully logged with the AI result file, a readable control summary, the status, error details if anything went wrong, and the total tokens consumed. The chatter keeps a record of every step.

Current Vendor Pricelist File in One Click

Select vendor and generate an Excel file with all of that vendor's current Vendor Pricelist lines. The file contains the vendor, product template, note, vendor product code, start date, end date, company, quantity, unit, unit price, transport, other fees (Autre frais), discount and lead time.

AI-Powered Price Matching

The AI compares the vendor's returned file with the current pricelist and extracts the latest price, quantity, discount, transport cost, other fees, lead time, start date and end date for each product, using product name, description, vendor code, packaging, family and brand, not the code alone.

Automatic Unit & Packaging Conversion

Prices are converted to the pack size used in Odoo. For example, a vendor price of 0.76 per kg becomes 19.00 for a pack of 25 kg. Transport and other fees are converted in the same way.

Drag & Drop Uploads

Drag and drop the vendor file and the custom pricelist file straight onto their fields.

Automatic Price History

When you apply the result, the module updates the line with the same start date, creates a new line for a new start date, and closes the other open lines by setting their end date to the new start date minus one day.

Guided Resolution of Unmatched Products

For every unmatched product, choose Map with Existing to use an existing Odoo product, or Create New Product to duplicate an existing product under the vendor's product name. The Vendor Pricelist line is then created or updated in the same way as for matched products.

Editable AI Prompt

Manage the default prompt from one central menu and edit it on a single record without changing the default.

Complete Logs & Status Monitoring

Track each run with its status, the AI result file, the AI Control Summary, error messages, the run date, the matched count and the total tokens used.

03 Open Pricelist Management > AI Vendor Pricelist Update. The list shows the Reference, Name, Vendor, Generated On, Matched count and Status of each update. Click "New" to create a new record.

04 In the new record, enter a name, select the Vendor and check the Company. Then click "Generate Pricelist File". The status bar shows the steps: Draft, Pricelist File Generated, AI Analysis Done and Applied.

05 After clicking "Generate Pricelist File", the state changes to Pricelist File Generated. The file IMPORT EXPORT TARIFS FOURNISSEURS.xlsx is available under Current Vendor Pricelist, and the Generated On date is filled in.

  • Open the downloaded Excel file to see the vendor's current pricelist lines. It contains the Vendor, Product Template, Note, Vendor Product Code, Start Date, End Date, Company, Quantity, Unit, Unit Price, Transport, Autre frais, Discount and Lead Time. These are the same 6 lines seen in the Vendor Pricelists screen.

06 In the Vendor Pricelist File field, click "Upload your file" and upload the price file received from the vendor. Then click "Run AI Analysis".

  • This is the vendor's price file (Proposition tarifaire) that was uploaded. It shows the vendor codes, product names, packaging, prices and the validity period from 14/07/2026 to 31/07/2026.

07 After the analysis, the state changes to AI Analysis Done and the AI Result File is created, here LOGNIB_FOOD_2026-07-14_READY_ODOO_IMPORT.xlsx. The Product Matching tab lists the products the AI is certain about, with start date, quantity, unit price, discount and lead time. The Apply Result is Pending until you apply. Click "Re-run AI Analysis" if you want to run the analysis again.

08 Open the Unmatched Products tab for the products the AI could not match with certainty. For each line, choose an Action and a Product:

  • Map with Existing: update the selected existing vendor pricelist product as it is.
  • Create New Product: duplicates the selected product and renames it to the vendor's product name.
  • Then click "Apply to Vendor Pricelist".

09 After applying, the state changes to Applied and a green "APPLIED" ribbon appears on the record.

10 After applying, the Vendor Pricelist shows the price history: when a product already has an open line with a different start date, the old line is closed with an End Date of the day before the new start date (Jul 13) and a new line is created from the new start date (Jul 14); if the start date is the same, the existing line is updated instead of creating a new one, and products resolved from Unmatched Products (Customizable Desk, BINGOIL PRO 10L) get new lines starting Jul 14.

11 Open the Log tab to see the AI Run Date, the number of Pricelist Lines, the Matched count and the AI Total Tokens Used.

What does the Vendor Pricelist AI Update module do?

It uses AI to compare the price file received from a vendor with the current Vendor Pricelist in Odoo, and prepares the new prices. After your review, it creates or updates the Vendor Pricelist lines automatically and keeps the price history correct.

Which files can I upload?

The vendor file can be the price file received from the vendor, such as an Excel sheet, a PDF or a Word document. The custom pricelist file must be an Excel file with the columns Product Template and Note.

What is the Generate Pricelist File button for?

It exports the current Vendor Pricelist lines of the selected vendor to Excel. The AI uses this file as the reference to match the vendor's new prices against, so it must be generated before the analysis.

What is the difference between Product Matching and Unmatched Products?

Product Matching contains the products the AI is certain about, and they are applied directly. Unmatched Products contains probable matches and new vendor products, and each one needs your Action and Product before it is applied.

What does Map with Existing do?

It links the vendor's product to an existing Odoo product and uses that product as it is.

What does Create New Product do?

It duplicates the selected product and renames the copy to the vendor's product name. The Vendor Pricelist line is created for this new product.

What happens to the old price when a new one is applied?

The old open line is not deleted. It is closed by setting its end date to the day before the new start date, so the history is kept.

What happens if the start date is the same as an existing line?

If that line has no end date, it is updated with the new values. Otherwise a new line is created.

Will the AI invent a price, a code or a product link?

No. The prompt forbids inventing any price, code, product link, discount, date, packaging or conversion. Doubtful matches go to the Unmatched Products tab and are never linked automatically.

Do I need to review the result before it is applied?

Yes. The result is only prepared by the analysis. Nothing changes in the Vendor Pricelist until you click Apply to Vendor Pricelist and confirm.

Can I change the AI instructions?

Yes. Edit the default prompt in the AI Prompt menu, or edit the prompt on one single record. A change on a record never changes the default prompt.

Do I need technical knowledge to use the module?

Daily use (generate, upload, analyze, review, apply) needs no technical knowledge. Only the first-time setup of the OpenAI API key needs an administrator.
