One Click Multi Variant Image Sync

Community Enterprise Odoo.sh

In Odoo's current system, product images must be uploaded individually for each variant. This can be time-consuming, especially for products with multiple variations in color and size. Our Variant Image Sync app simplifies this process by allowing users to upload an image for one variant, and the image will automatically sync across all other variants of the same color.

01 When you have variant combinations like Color and Size, and need to upload the same image for the a specific color across all sizes, you can do so by going to the Variants section from the product.

02 From this list, open the desired product variant.

03 If you have opened the White color and S size variant, you can add one or more images using the "Add a Media" option. Then, click on "Update Images to All Size Variant" to apply those images to all size variants that have the White color.

04 Afterward, to cross-check, open other size variants with the White color, and you will see that the images are automatically uploaded to all size variants with the same color.
