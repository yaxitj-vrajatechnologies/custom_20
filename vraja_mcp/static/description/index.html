MCP Assistent

Community Enterprise Odoo.sh

The MCP Assistant brings a chat-style AI assistant directly into Odoo. Users can give plain-English instructions such as “create a sale order” or “show open quotations,” and the AI performs the requested action through the MCP server. Each chat is scoped to one Odoo model and one operation: Read, Create, Update, or Delete.

The module also provides document reading functionality. Users can upload PDFs, images, handwritten forms, Excel, CSV, email, or text files. The AI reads the document according to the user's requirement, extracts relevant information, and converts it into structured data for review. Once confirmed, the extracted data can be used to create or update Odoo records.

Built-in guardrails prevent incorrect actions by resolving records through live searches and asking for clarification when matches are unclear. The AI re-checks record status before updates or deletes, while chats, AI responses, and token usage are stored for future reference. Records are never confirmed, posted, validated, or invoiced without explicit user instructions.

Natural Language Odoo Automation

Interact with Odoo using plain English. Search, create, update, or manage records without technical terms, complex filters. Simply describe the task, press Send, and the AI works with your live Odoo data through MCP.

Per-Model Access Control

Administrators can define which Odoo models are available to the AI and which operations are permitted for each model. The chat displays live Allowed and Not Allowed statuses for Read, Create, Update, and Delete operations.

Live Record Resolution Through MCP

The AI works with live Odoo records instead of relying on stored assumptions. Customers, products, and other references are resolved through live searches and verified before use. When multiple records match, the AI asks for clarification instead of making an uncertain selection.

Multiple File Formats and Files

Upload multiple files in a single message and analyze them together. Supported formats include JPG, JPEG, PNG, PDF, XLSX, XLSM, CSV, MSG, and ODT.

Two-Step Workflow: Analyze Then Act

First, the AI analyzes the uploaded document and displays the extracted JSON for verification. After reviewing the extracted information, the second step uses your instruction and the verified JSON to create or update the Odoo record through MCP.

Safe Create, Update, and Delete

Before creating records, the AI verifies the partner and products against Odoo. Header and line data are processed together to create exactly one record per request. Before updates or deletions, the AI re-checks the current record state. After every operation, it re-fetches the record to verify the result.

Conversation Memory and History

The assistant maintains the complete conversation history and uses previous messages for follow-up requests. Conversations are stored with the chat record, allowing users to reopen previous chats and continue their work.

Token Usage Tracking

Each AI response displays the total number of tokens used. This provides visibility into AI usage across document analysis and Odoo automation tasks.

Modern Chat Interface

Use a clean, Odoo-integrated chat interface with a sidebar for selecting the Odoo model, operation, and AI agent. Drag and drop files directly into the message area, use Ctrl + Enter or Cmd + Enter to send, and prevent duplicate requests while an operation is running.

03 On the right side click on the login user and open My Preferences. Go to the Security tab and click "Add API Key" to create an Odoo MCP API key.

04 In the New API Key window, enter the name "MCP Key" and select the scope "MCP only" with 1 Year validity. Then click "Generate key". The MCP key is an Odoo API key. 05 Copy the generated API key from the "API Key Ready" window and click Done. The key is shown only once, so save it safely.

06 Open Settings and search "odoo mcp". Paste the copied key into the Odoo MCP API Key field under MCP AI Automation, then click Save.

07 In Settings search "mcp" and tick "Enable MCP Access" under MCP Server Configuration. Then click "Manage MCP Available Models".

08 In the MCP Models list, click "New or Select Multiple Models" at the top to add the required models and their rights.

09 In the Enable Models for MCP window, add sale.order, sale.order.line, res.partner and product.product. Under Access Settings tick Allow Read, Allow Create, Allow Update and Allow Delete, then click "Enable Selected Models".

What does the MCP Assistant module do?

The MCP Assistant adds a chat-based AI assistant to Odoo. Describe your task in plain English, and the AI can read, create, update, or delete records in your live Odoo database through the Model Context Protocol (MCP). It can also analyze documents such as PDFs, images, Excel files, and emails and use the extracted information to create or update Odoo records.

Which AI does the module use?

The module uses OpenAI. The LLM model configured on the AI Agent selected for the chat processes your request. Only AI Agents configured with a supported GPT model are available for selection. The OpenAI API key is configured through the AI Dashboard.

Where do I configure the API keys?

The OpenAI API Key is configured in the AI Configuration Setting . The Odoo MCP API Key is configured under Settings → General Settings → MCP AI Automation.

Why do I need an Odoo MCP API key?

The Odoo MCP API key allows the AI service to securely connect to your Odoo database through the MCP endpoint. It is used to search, create, update, and delete records according to the permissions configured for the selected model and operation.

Which file formats are supported?

The module supports the following file formats:

Images: JPG, JPEG, PNG, GIF Documents: PDF, ODT Spreadsheets: XLSX, XLSM Data files: CSV Emails: Outlook MSG files

Can I upload multiple files?

Yes. You can attach multiple files to the same message. The AI analyzes the uploaded files together as a single document set.

Do I need to attach a document to use the assistant?

No. Documents are optional. You can use the assistant without attachments by selecting the required model and operation and entering your instruction in plain English.

Can I analyze another document in the same chat?

Each chat is designed to process one document set. To analyze a different document set, start a new chat from AI Chats.

Does the module support handwritten and scanned documents?

Yes. The AI can analyze images and scanned documents visually, including handwritten information. If a value or row cannot be read reliably, it is reported as an issue instead of being guessed.

Will the AI confirm, validate, post, or invoice records?

No. The AI does not automatically confirm, validate, post, or invoice records unless you explicitly request the corresponding operation and it is permitted by the configured access rules.

Does the assistant remember previous conversations?

Yes. Messages and responses are stored on the chat record. The assistant can use previous conversation context when handling follow-up requests. You can reopen a previous chat from AI Chats and continue the conversation.

Do I need technical knowledge to use the module?

No technical knowledge is required for regular use. Users can select a model, choose an operation, attach documents, and enter instructions using natural language.
