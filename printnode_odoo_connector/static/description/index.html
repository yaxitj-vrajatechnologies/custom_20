The PrintNode Odoo Connector module provides seamless integration between Odoo and PrintNode, enabling automated and remote printing directly from Odoo to printers connected through PrintNode. PrintNode Odoo Connector simplifies printing by sending print jobs directly from Odoo to printers such as ZPL label printers, ESC/POS receipt printers, PDF printers, and PCL or PostScript printers commonly used for standard Odoo reports. The module imports computers from PrintNode along with their associated printers and supported paper sizes, allowing administrators to manage available printing devices directly within Odoo. It also allows configuring automatic printing rules, which can trigger the direct printing of documents or attachments based on defined conditions. This helps automate printing workflows and reduces manual intervention. The module provides report printing settings where administrators can configure specific users who can access the Print Wizard to print reports directly through PrintNode from Odoo. Additionally, the module supports direct label printing, allowing shipping labels or product labels to be printed automatically through PrintNode without downloading the files manually. This integration ensures efficient printer management, automated document printing, and streamlined printing workflows between Odoo and PrintNode.

Print your Odoo documents instantly without downloading files first. Reports, invoices, shipping labels, and attachments can be sent directly from Odoo to your connected printers

The solution is compatible with the printers you already use. Any printer capable of standard document printing can work with the PrintNode Odoo Connector, allowing you to print directly from Odoo with speed, reliability, and effortless printing.

05 Now that all available printers and computers have been synchronized for direct printing, you just need to enable the Direct Printing option for Report Printing and Print Shipping Label for Labels printing. The default printer and paper format are used when no specific printer is selected for printing a document and for printing a label.

06 Now in the Print Rules menu, you can see all the available printing rules. You just need to activate the rule you want to use.

07 When you click on a specific rule, you just need to activate it and select the printer, paper format and copies. If you want to print only specific records, you can add filters (domain conditions) so that the print job is created only when the conditions are satisfied.

08 We created a sales order for Azure Interior. When the order is confirmed, a print job is automatically created and the document is printed instantly. This enables effortless printing with no need to download the document, improving overall efficiency.

09 After confirming the sales order, a print job request is created in the Print Job menu. You can view the print job record with the status Done, which indicates that the document was printed successfully through PrintNode.

10 PrintNode Connector includes a logger to track all operation records between Odoo and PrintNode. you can see the log details for import process of Computers and Printers, You can open each record to review its detailed information directly in the logbook.

11 After configuring the settings at the Company level, you also need to configure the Delivery Method settings for PrintNode. For each delivery method, select the printer, paper format, and number of copies. You can assign a specific printer to each delivery method to ensure reliable and accurate printing.

12 Now everything is set to print the shipping label directly through PrintNode. When you validate the order, the label is generated and automatically printed via PrintNode.

13 You can view all the details related to shipping labels in the Print Job → Shipping Labels menu. Also we have a option to reprint that specific label using Print Label button. same you can view the log book to tack label records between odoo and PrintNode.

14 You can also print a specific report by clicking the Print option from the Actions menu. To enable this feature, some configuration is required. Navigate to Settings > Report , where you can grant users permission to print specific reports. In this section, you can also configure the printer and paper format that should be used for printing the report.

15 Create a Sales Order and confirm it. Then, from the Actions → Print → PDF Quote server action, open the Print Wizard. In the wizard, enter the number of copies you want to print and click Print. 18 We also have a cron job that runs daily to delete print jobs older than 15 days, To keep the system clean and optimized.

What types of printers are supported by this module?

Our module supports all type of printers, including ZPL, ESC/POS, and network printers. And can Print Document based on printer

Can I print shipping labels for any carrier?

Yes, you can print shipping labels for any carrier once the PrintNode configuration is properly set up.

Can I track print operations?

Yes, the module includes a logger that records all operations between Odoo and PrintNode. Each print job’s details can be viewed directly in the Log Book, including status, system, printer, and paper information.

Can multiple copies be printed?

Yes, when using the Print Wizard or report printing, you can specify the number of copies to print.

Are all printing rules built-in, and can I customize them?

Yes, all rules come pre-configured (built-in). You can also customize each rule by selecting the printer, paper format, and adding filters or domain conditions to control which records are printed.

What happens if a printer is not configured in the rules?

If no printer is configured for a rule, the system will use the default printer and paper format set at the User or Company level to print the document.
