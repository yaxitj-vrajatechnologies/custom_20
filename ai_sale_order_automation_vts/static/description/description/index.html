AI SALE ORDER AUTOMATION THROUGH MCP

Community Enterprise Odoo.sh

The Auto Create Sale Order Through MCP module provides a complete solution for converting customer order documents into draft Odoo Sale Orders using AI. Instead of manually entering every order line, users can upload the customer document and let the AI analyze the order. The module uses Anthropic Claude to extract customer, product, and quantity information and connects with Odoo through the MCP server to find the customer, match products, apply mappings and create the Sale Order.

Customers can send orders in different formats, including scanned PDFs, images, handwritten order sheets, Excel files, email files and text documents. The module analyzes the document row by row, extracts ordered products and quantities, ignores rows that were not ordered, and displays the extracted information for review. Users can either review the extracted lines before creating the Sale Order or use the auto-create option to analyze the document and create the Sale Order in one workflow.

The module also improves product matching through Product Mapping. When a customer product is mapped to the correct Odoo product, the mapping is saved and reused for future orders, helping ensure consistent product matching.

Every run is fully logged with the extracted JSON, MCP creation response, processing status, error details, AI model information and total tokens consumed. Users can review and update extracted products and quantities when required. The Sale Order is always created as a draft and is never confirmed automatically.

AI-Powered Order Reading

Automatically reads customer order documents, including handwritten and scanned forms, and extracts the customer, order reference, dates, delivery details, product references, descriptions, quantities, units and prices.

Multiple File Formats & Multiple Files

Upload images (JPG, JPEG, PNG), PDF, Excel (XLSX, XLSM, XLS), CSV, Outlook messages (.msg) and OpenDocument text (.odt). Upload any number of files for one order and they are treated as one combined order.

Smart Row Handling & Unit Conversion

Only products with a real ordered quantity become Sale Order lines. Blank,zero and crossed-out rows are listed as Ignored Lines. Quantities are never invented.

Automatic Customer & Product Matching through MCP

The AI searches your live Odoo data through MCP to find the customer and match each product by internal reference first and by description second. It never fills a gap with a random or default product.

Guided Review & One-Click Update

Review every extracted line in a table, map or correct the Odoo product, edit the quantity, and apply all changes to the Sale Order with a single click on Update Sale Order. No duplicate lines are created.

Learning Product Mapping

Every product you map or correct is saved and reused automatically on future orders. Each mapping also has a quantity multiplier for products that are sold in a different size than the one written on the customer document.

Editable AI Prompts & Customer Instructions

Manage the extraction and creation prompts from one central menu, edit them on a single record, and add customer-specific instructions that are applied automatically whenever that customer is selected.

Two-Call AI Workflow (Extraction + Creation)

The order is processed in two separate AI calls. The first call reads the document and returns a structured JSON for verification. The second call takes that exact JSON and uses MCP to create the Sale Order in Odoo. You can check and correct the extracted data between the two calls, so nothing is created before you approve it.

One-Click Direct Sale Order Creation

Enable Auto-Create Sale Order and a single click on Analyze & Create Sale Order runs both calls back to back. The document is read, the JSON is generated and the draft Sale Order is created in Odoo with no manual review in between. This suits trusted customers and repeat orders.

Complete Logs & Status Monitoring

Track every run with extraction status, creation status, customer match status, extracted JSON, creation response, error messages, AI model used and token usage for both the extraction and the creation step.

01 After installing the modules, the Odoo home screen shows the apps used by this solution. The highlighted app AI Dashboard.

02 Open AI Dashboard and click the Configuration menu at the top. Under AI Provider select Claude (Anthropic), then enter the Claude API Key, Claude Model and Max Tokens in the Claude (Anthropic) Settings section.

03 On the right side click on the login user and open My Preferences. Go to the Security tab and click "Add API Key" to create an Odoo API key.

04 In the New API Key window, enter the name "MCP Key" and select the scope "MCP only" with 1 Year validity. Then click "Generate key". The MCP key is an Odoo API key. It lets the AI connect to your Odoo database to find the customer and products and create the sale order. It is not the Claude or OpenAI key.

05 Copy the generated API key from the "API Key Ready" window and click Done. The key is shown only once, so save it safely.

06 Open Settings and search "odoo mcp". Paste the copied key into the Odoo MCP API Key field under MCP AI Automation, then click Save.

07 In Settings search "mcp" and tick "Enable MCP Access" under MCP Server Configuration. Then click "Manage MCP Available Models".

08 In the MCP Models list, click "New or Select Multiple Models" at the top to add the required models and their rights.

09 In the Enable Models for MCP window, add sale.order, sale.order.line, res.partner and product.product. Under Access Settings tick Allow Read, Allow Create, Allow Update and Allow Delete, then click "Enable Selected Models".

What does the Auto Create Sale Order Through MCP module do?

It uses AI to read customer order documents and automatically create draft Sale Orders in Odoo. It saves hours of manual entry by extracting the customer, products and quantities from files such as PDFs, photos, Excel sheets and emails, and then matching them to your Odoo customers and products.

Which file types are supported?

Images (JPG, JPEG, PNG), PDF, Excel (XLSX, XLS), CSV, Outlook messages (.msg) and OpenDocument text (.odt). Any other file type is rejected with a clear message.

Can I upload more than one file for the same order?

Yes. You can upload any number of files on one record and they are treated as one combined order.

Which AI does the module use?

The module uses Anthropic Claude. You enter the Claude API Key and choose the model on the AI Configuration record of the AI Agent app.

Where do I enter my API keys?

The Claude API Key is entered in the AI Configuration record in the AI Dashboard App, The Odoo MCP API Key is entered under Settings > General Settings > MCP AI Automation.

Why do I need an Odoo MCP API key?

The AI connects to your Odoo database through the MCP endpoint to search for customers and products and create Sale Orders. The key must be an Odoo API key with the "MCP only" scope. An AI provider API key cannot be used in this field. Your Odoo address must also be configured in the web.base.url system parameter and be accessible to the AI service.

Does it work with handwritten order sheets?

Yes. The module can analyze photos and scanned documents visually and link handwritten quantities to their corresponding product rows. Unclear or unreadable handwriting is not guessed.

What happens to rows that have no quantity?

Rows without a quantity are not added to the Sale Order. They are displayed in the Ignored Lines tab so you can verify that every document row was processed.

Do I need to review the order before it is created?

No. You can choose the workflow that suits you. Keep Auto-Create Sale Order disabled to analyze, review, and correct the extracted lines first. Enable it to analyze the document and create the Sale Order in a single workflow.

What happens if the customer is not found?

No Sale Order is created. The record displays Customer Not Found along with the relevant reason. You can select the correct customer on the record and run the process again.

What happens if a product cannot be matched?

The product line is skipped and shown as Not Added. You can manually select the correct Odoo product and click Update Sale Order. The product mapping is saved for future orders.

What if the same product is written differently on different documents?

You can map the customer product description to the correct Odoo product once. The saved mapping is reused when a similar description appears in future orders. Mappings can also be managed from the Product Mapping menu.

Can I change the AI instructions?

Yes. You can edit the common prompts from the AI Prompt menu, customize prompts for an individual automation record, or add customer-specific instructions from the customer form.

How do I track API token usage?

Each record includes a Logs tab showing the input, output, and total tokens used during the extraction and Sale Order creation steps, along with the overall token usage for the record.

What happens if the AI call or Sale Order creation fails?

The record moves to the Error state, and the error message and response are stored on the record. After correcting the issue, you can run the required step again.

Do I need technical knowledge to use the module?

No technical knowledge is required for daily use, such as uploading documents, analyzing orders, reviewing lines, and creating Sale Orders. Only the initial API key configuration requires administrator access.
